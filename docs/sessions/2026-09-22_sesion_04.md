## 5. Checklist Obligatorio de Calidad Pre-Cierre

- [x] **Separación Estricta de Capas:** Dominio (`src/domain/`), Repositorios (`src/repositories/`), Servicios (`src/services/`) y Excepciones (`src/core/exceptions.py`) rigurosamente segregados. Cero SQL en servicios o UI.
- [x] **Principios SOLID Cumplidos:**
  - *Single Responsibility (SRP):* `UserRepository` solo persiste usuarios; `AuditRepository` solo persiste bitácora; `UserService` y `AuditService` encapsulan los casos de uso.
  - *Dependency Inversion (DIP):* Servicios admiten inyección de repositorios y rutas de base de datos.
  - *Open/Closed (OCP):* Nuevos eventos sensibles se agregan sin alterar contratos existentes.
- [x] **Encapsulamiento POO Estricto:** Atributos privados con guion bajo (`_`) y propiedades `@property` en todas las clases.
- [x] **Inalterabilidad de Auditoría (Append-Only):** Cero soporte para actualización o eliminación de registros históricos.
- [x] **Seguridad Criptográfica:** Hashing mediante `bcrypt` con sal dinámica de 12 rondas. Prohibido texto plano.
- [x] **Consultas Parametrizadas:** 100% de consultas SQL construidas con tuplas `?` contra inyecciones SQL.
- [x] **Integridad de Tipos e Imports:** Tipado estático explícito mediante `typing` en todos los métodos nuevos y modificados.
