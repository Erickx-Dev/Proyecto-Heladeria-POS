## 5. Checklist Obligatorio de Calidad Pre-Cierre

- [x] **Separación Estricta de Capas:** No se incluyó código SQL en la UI (no se modificó UI en este turno). Dominio desacoplado de dependencias externas.
- [x] **Principios SOLID Cumplidos:**
  - *Single Responsibility (SRP):* Responsabilidades de autenticación, auditoría y modelos de datos claramente segregadas.
  - *Liskov Substitution (LSP):* `Administrador` y `Empleado` son sustituibles como `Usuario`.
  - *Dependency Inversion (DIP):* `AuthService` admite inyección opcional de `AuditService` y `db_path`.
- [x] **Encapsulamiento POO:** Atributos privados con guion bajo (`_`) y propiedades `@property` en todas las clases de dominio y servicios.
- [x] **Transacciones ACID en Repositorios:** Operaciones compuestas de inserción en servicios ejecutadas con context manager `with conn:`.
- [x] **Integridad de Tipos e Imports:** Tipado estático explícito mediante `typing` (`Optional`, `Union`, `List`, `Path`).
- [x] **Seguridad y Criptografía:** Contraseñas procesadas estrictamente con `bcrypt` (12 rondas de costo); sin contraseñas en texto plano en disco ni memoria.
